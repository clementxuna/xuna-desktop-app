XUNA AI for Windows

Your XUNA workspace in its own window, without a browser tab to lose. It updates itself, so it's always the newest XUNA.

Download for Windows Open in your browser

This installer is for Windows PCs. Open this page on your PC to install it, or use XUNA AI in your browser on this device.

  • Windows 10 & 11
  • 64-bit
  • About 115 MB
  • Updates automatically
Install

Up and running in a minute

One download and three quick steps. After that, XUNA AI keeps itself up to date in the background.

  1. Step 1

    Download

    Save XUNA-AI-Setup.exe. If your browser says the file isn't commonly downloaded, choose Keep.

  2. Step 2

    Install

    Open the file. If Windows shows Windows protected your PC, choose More info, then Run anyway.

  3. Step 3

    Sign in

    XUNA AI opens as soon as it's installed. Sign in the same way you do on the web.

Windows shows these warnings because the app isn't code-signed yet. If there's no Run anyway option, Smart App Control is blocking unsigned apps on that PC. Use XUNA AI in your browser there for now.
